动画说明

设备出现 — @keyframes fadeIn:从 opacity:0;transform:translateY(8px) 渐入上移,stagger 0.2s 间隔,逐个出现。

在线指示 — @keyframes pulse:绿点呼吸缩放 scale(1→1.4→1),2s 循环。

主题切换 — toggle 滑动,`document.documentElement` class 切换 `dark`,所有颜色用 CSS 变量驱动,0.3s 过渡。

进度条 — 宽条 + shimmer 流动高光(从左扫到右)。完成时绿色脉冲。
