SendSent UI 现代化:选择视觉风格

当前界面是 Tauri 模板默认样式(白底黑字,rudimentary)。你希望整体风格走向哪个方向?

A

macOS 原生 / Apple HIG

磨砂玻璃(blur)、SF 字体风格、圆角卡片、系统级配色。像 AirDrop 或系统设置界面。桌面端 Mac 体验、iOS 也融合。

B

现代暗色 / 科技感

深色主题、微妙的渐变色强调、紧凑布局。类似 Vercel/Linear/Raycast 的气质。开发者和科技用户偏好。

C

多彩 / 亲切友好

明亮色彩、大卡片布局、圆润边角。像 LocalSend 或现代聊天应用。消费者级、对新手友好。
