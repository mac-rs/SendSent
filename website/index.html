01 · SPEED

快,是工程出来的

从协议帧到内核调用,每一层都为吞吐让路。不是"优化过",是从第一行代码就按打满网卡设计。

S/01

多连接分片

大文件按字节区间切开,分散到 16 条 TCP 连接同时收发;小文件轮询分发、流水线发送,不排队。网卡有几快,它就有几快。

S/02

零拷贝 sendfile

数据在内核态从文件描述符直达网卡,绕过用户态拷贝(默认可开关);TLS 模式或不支持时自动回退 pread + write,速度与兼容兼得。

S/03

为局域网调优

16 MiB Socket 收发缓冲、TCP_NODELAY、极简二进制协议帧——控制帧与数据帧分离,协议本身几乎零开销。

S/04

Rust 核心,原生界面

传输引擎是一个共享的 Rust core:桌面、iOS、Android 跑同一份代码,速度与行为三端一致,没有 WebView 的性能税。

02 · SECURITY

隐私是默认值

文件走点对点直连,架构上就不存在"经过我们服务器"这回事。需要更多确定性时,再打开加密。

PLAIN · 极速模式

速度优先

默认明文 + sendfile 零拷贝,吞吐拉满。适合可信的家庭与个人局域网——毕竟数据压根不出门。

03 · DISCOVERY

打开,就在

B

扫码或 IP 直连
